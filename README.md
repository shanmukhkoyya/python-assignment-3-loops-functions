# Python Assignment 3: Loops and Functions

## Project Overview
This repository contains my Python Assignment 3, focused on practicing loops, control statements, and user-defined functions through three beginner-friendly programs.

## Programs Included

### 1. Number Guessing Game
- Generates a random number from 1 to 10.
- Gives the user up to three valid guesses.
- Uses a `while` loop, conditional statements, `continue`, `break`, and a `while ... else` block.
- Provides feedback when a guess is too high, too low, correct, or outside the allowed range.

### 2. Multiplication Table Generator
- Accepts a number from the user.
- Uses a `for` loop with `range(1, 11)` to display the multiplication table from 1 to 10.

### 3. BMI Calculator
- Defines a function named `calculate_bmi(weight, height)`.
- Calculates BMI using `weight / (height ** 2)`.
- Accepts weight in kilograms and height in meters.
- Displays the result to two decimal places.

## Concepts Practiced
- `while` and `for` loops
- `range()`
- Conditional statements: `if`, `elif`, and `else`
- Loop control: `break` and `continue`
- Functions, parameters, and `return`
- User input with `input()`
- Type conversion with `int()` and `float()`
- Formatted output

## How to Run
1. Open `Python Assignment 3.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
2. Run the cells in order.
3. Enter the requested values when prompted.
